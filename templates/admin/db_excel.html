Panduan Import
  • Nama sheet harus sama persis dengan label tabel (misal Donatur, Chart of Accounts)
  • Baris pertama = header kolom. Data mulai baris kedua
  • Kolom id terisi → data di-update (overwrite). Kolom id kosong → data ditambahkan baru
  • Tabel transaksi, koleksi, dan jurnal bersifat read-only (export saja, tidak bisa diimport)
  • Backup otomatis dibuat sebelum setiap import — bisa di-restore dari menu Backup
  • Kolom tambahan (seperti coa_nama, donatur_nama) diabaikan saat import — hanya kolom asli tabel yang diproses
